# Simba 💖

A playful and cute interactive apology web page built with HTML, CSS, and JavaScript.

## Features
- Interactive dodging "No" button that responds to hover/clicks with playful teasing messages.
- Expanding "Yes" button with animated floating emojis and hearts burst.
- Smooth transition to a cute second reveal screen.
- Responsive mobile & desktop layout.

## Live Demo / Usage
Simply open `index.html` in any browser!
