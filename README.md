# Simba 💖

A playful and cute interactive apology web page built with HTML, CSS, and JavaScript.

## 🚀 Live Demo & Deployment
- **GitHub Pages**: [https://anurampranav.github.io/Simba/](https://anurampranav.github.io/Simba/)

### How to Enable GitHub Pages (One-time setup on GitHub):
1. Go to your repository settings: [GitHub Pages Settings](https://github.com/Anurampranav/Simba/settings/pages).
2. Under **Build and deployment > Source**, select either:
   - **GitHub Actions** (recommended — uses the included automated workflow), OR
   - **Deploy from a branch** -> Branch: `main` / `/(root)`.
3. Save, and your live site will be ready at [https://anurampranav.github.io/Simba/](https://anurampranav.github.io/Simba/).

## Features
- Interactive dodging "No" button that responds to mouse/touch with teasing messages.
- Expanding "Yes" button with floating hearts and confetti sparkles.
- Transition to cute apology resolution card.
- Fully responsive across desktop and mobile devices.
